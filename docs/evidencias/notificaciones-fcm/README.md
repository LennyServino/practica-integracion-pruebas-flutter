# Notificaciones FCM — No aplica

El proyecto **no integra Firebase Cloud Messaging** (ver [01-declaracion-alcance.md](../../01-declaracion-alcance.md)).
Por eso los casos CP-14 a CP-17 (token, primer plano, segundo plano y app cerrada) se registran como **No aplica** en la [plantilla de pruebas](../../03-plantilla-pruebas.md).
